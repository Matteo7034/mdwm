Requirements
------------
In order to build dwm you need the Xlib header files.
- feh
- scrot
- xorg
- st (mst [Vai alla sezione Installazione](https://github.com/Matteo7034/mst) ) 
- dmenu
- picom
- pipewire (systemd debian)

Installation
------------
```bash
cp ~/mdwm/scripts/.xinitrc ~/
cd ~/mdwm
sudo make clean install
```
